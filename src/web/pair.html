Pair this device

This browser has not been paired with this host. Being on the tailnet gets you to the door; pairing is what opens it.

Where do I get a code?

On the machine running the host, run:

oh-my-agents pair

It prints a code that works once, for five minutes. Pairing lasts until you revoke this device with oh-my-agents revoke, or from the Devices page on a paired browser.
